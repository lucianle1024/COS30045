Read the numbers carefully

What these figures can tell us.

These are hospitalisation counts, not unique people, population-adjusted rates, or a measure of how dangerous a mode of transport is. Exposure, population size and reporting practices can affect comparisons.

The original workbook contains six cause categories. This story uses only Traffic and sums the Hospitalisations field. The raw rows are aggregated records, so counting rows would give the wrong result.

Source: BITRE Hospitalised Injury Data, September 2023 publication, using AIHW National Hospital Morbidity Database data. The source dictionary describes definitions, exclusions and the 2012 and 2017 reporting changes.
